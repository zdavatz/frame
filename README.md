# Frame

Diaschau für einen Bilderrahmen (iPad): alle 3 Sekunden ein Bild aus einem
Google-Drive-Ordner, mit Überblendung, Bildschirm bleibt wach.

Die Bilder liefert eine Google-Apps-Script-Web-App (`?liste=1`, `?bild=ID`,
JSON). Ihre Bereitstellungs-ID steht nicht hier, sondern hinter dem `#` der
Adresse:

    https://zdavatz.github.io/frame/#<Bereitstellungs-ID>

Am iPad: Adresse in Safari öffnen, Teilen → «Zum Home-Bildschirm». Vom
Home-Bildschirm aus läuft die Seite ohne Safari-Leisten im Vollbild.
